# Documentation

The [theory and algorithm reference](https://jmartinon.github.io/sl2cfoamxx/)
explains the mathematical model, Wigner and booster recurrences, coherent
states, tensor contractions, and internal execution.

Installation and API usage are covered by the repository guides:

- [Building the library](building.md)
- [C++](cpp-api.md), [Python](python.md), [Julia](julia.md), and
  [Mathematica](mathematica.md)
- [Configuration and defaults](configuration.md)
- [Scientific conventions](scientific-conventions.md)
- [Regression testing](testing.md)

The documentation website's editable sources, figure sources, and build
configuration are kept together in [`.documentation/`](../.documentation/README.md).
